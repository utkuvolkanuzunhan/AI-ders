# Kişiye özel katman (henüz boş)

İleride burada kişi profilleri durabilir (ör. odak süresi, ezber/hesap ağırlığı, zayıf olduğu konu türleri). Kişisel veri içermemeli: yalnız tercih kodları ve genel tercihler.

Şimdilik kişiye özel her şey kullanıcının kendi proje klasöründe, `yerel/ayarlar.md` dosyasında tutulur (şablon: kurulum/yerel-ayarlar-sablonu.md).
